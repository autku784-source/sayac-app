# Sayaç Uygulaması

HTML, CSS ve JavaScript ile yaptığım basit bir sayaç uygulaması.

## Özellikler
- Sayıyı artırma
- Sayıyı azaltma
- Sıfırlama

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Nasıl Çalıştırılır?
1. Dosyaları indir
2. `index.html` dosyasına çift tıkla
3. Tarayıcıda açılır

## Not
Web geliştirmeyi öğrenirken yaptığım ilk projelerden biri.
